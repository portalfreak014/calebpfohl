# Chaos Mode vocabulary and soundtrack correction

Supersedes the initial prototype's unit-JSON loader, procedural soundtrack, file picker, and corresponding sections of chaos-mode.md. The initial loader incorrectly assumed every legacy unit JSON contained questions. Unit 1 has an empty chapters object even though its Markdown glossary contains vocabulary. Chaos now reads data/glossary/unitN-glossary.md, the same core source used by the regular quiz, parses Chapter headings and Arabic/Meaning table rows, filters against manifest availability, and deduplicates exact word/meaning pairs. Choice distractors come from the selected chapter/unit pool and exclude entries sharing the prompt or correct translation. Ordinary learner progress is still untouched.

Setup is Unit, Chapter, Start. Direction, round length and reduced effects live in collapsed Round settings. Mute, volume and reduced effects remain accessible. No local-file picker, synth loop, music opt-in checkbox, or song selector. The existing assets/running_in_the_nineties.mp3 is the default looping soundtrack; Start invokes play directly before awaiting vocabulary to preserve browser activation. Blocked playback offers a Play music retry, and failed loading stops audio. Pause, backgrounding, results and page exit stop/pause playback. Future curated song choices remain a roadmap item. This change references an existing repository asset and does not establish its licensing status.

The shimmer entry now repositions immediately before the theme toggle when that toggle arrives asynchronously, rather than staying at its initial fallback position near the hamburger. Its accessible name and tooltip remain while no visible text label is added.

Required checks: Unit 1 Chapter 1 and all chapters; Unit 8 legacy-versus-glossary content; both directions; single missed-word retry; repeated start, mute/unmute, autoplay rejection/retry, background during loading/countdown, and header ordering with delayed theme loading. Browser/Netlify playback tests have not been run in preparing this change.
